# TileNamer v0.1.6 RC1

Windows용 1차 배포 후보입니다.

## 실행

`TileNamer.exe`를 실행합니다. 일반 GUI 실행에는 별도 Python 설치가 필요하지 않습니다.

`.ase` 또는 `.aseprite` 파일을 열려면 Aseprite가 별도로 설치되어 있어야 합니다. TileNamer는 `ASEPRITE_PATH`, PATH, Steam 및 일반 설치 위치 순서로 외부 Aseprite 실행 파일을 찾습니다.

## 주요 기능

- 타일시트 Grid 기반 Assignment 및 multi-cell/비정형 선택
- 프로젝트 저장·불러오기와 export destination 관리
- Aseprite 레이어·Grid 연동
- Solid, Wall, Platform, Top Sequence 배치 미리보기
